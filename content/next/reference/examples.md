# Examples

| Example | Description |
|---|---|
| [`app-router-simple`](https://github.com/i18next/next-i18next/blob/master/examples/app-router-simple) | App Router with locale-in-path (`/en/...`) |

| [`pages-router-ssg`](https://github.com/i18next/next-i18next/blob/master/examples/pages-router-ssg) | Pages Router with static export (`output: 'export'`) |
| [`pages-router-auto-static-optimize`](https://github.com/i18next/next-i18next/blob/master/examples/pages-router-auto-static-optimize) | Pages Router with client-side loading via chained backend |
