# migrate-config

Converts an `i18next-parser.config.js` file into an `i18next.config.ts`.

```bash
npx i18next-cli migrate-config

# Using custom path for old config
npx i18next-cli migrate-config i18next-parser.config.mjs
```

The rest of the move, including the Node.js version: [Migration from i18next-parser](../guides/migration-from-i18next-parser.md).
